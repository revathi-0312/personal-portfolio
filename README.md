# 🌐 Personal Portfolio Website (3D Interactive)

A modern, interactive 3D personal portfolio website built with React, Three.js, TypeScript, and Tailwind CSS. Features animated 3D shapes, real-time typing effects, smooth animations, and a comprehensive showcase of projects, skills, education, and experience.

## ✨ Features

### 🎨 Frontend
- **3D Interactive Background** - Animated 3D shapes using Three.js and React Three Fiber (R3F)
- **Real-time Typing Effect** - Auto-cycling role descriptions with smooth typing animations
- **Smooth Animations** - Staggered entrance animations (slide-in from bottom/left)
- **Interactive Profile Card** - Rotating animated rings with glowing effects
- **Responsive Design** - Mobile-first approach with cross-platform compatibility
- **Glassmorphic UI** - Modern dark theme with frosted glass effects
- **Component-Based Architecture** - Reusable, scalable React components

### 📋 Sections
1. **Home** - Hero section with 3D background, profile image, and CTA buttons
2. **About** - Personal bio, skills breakdown (Frontend, Backend, Tools, Languages), 3D background
3. **Education** - MCA, B.Com, Class XII/X with CGPA and achievements
4. **Projects** - 6 featured projects with tech stack, highlights, and 3D background
5. **Skills** - Certifications, achievements, and Deloitte virtual experience
6. **Contact** - Social links (GitHub, LinkedIn, Email)

## 🚀 Tech Stack

### Frontend
- **React 18** - UI library
- **TypeScript** - Type safety and better DX
- **Three.js** - 3D graphics library
- **React Three Fiber (R3F)** - React renderer for Three.js
- **Drei** - Helpful utilities for R3F (Float, OrbitControls, Stars)
- **Tailwind CSS** - Utility-first CSS framework
- **Shadcn UI** - Component library built on Radix UI
- **Lucide React** - Icon library

### Build & Deployment
- **Vite** - Next-gen build tool for fast development
- **Vercel** - Deployment platform for optimal performance
- **Git** - Version control
